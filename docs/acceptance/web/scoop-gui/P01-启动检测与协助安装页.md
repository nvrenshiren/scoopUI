## 1. 启动检测

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 首次启动且没有语言偏好 | 启动应用并完成语言选择 | 语言选择后再检测 Scoop |
| Scoop 可用 | 启动应用 | 不要求用户填写安装配置,直接进入日常管理功能 |
| Scoop 不可用 | 启动应用 | 说明无法进入日常管理的原因并提供协助安装能力 |
| 检测过程失败 | 启动应用 | 说明检测未能完成并提供适当的恢复/重试路径;不得伪报 Scoop 可用 |

## 2. 安装配置

- 协助安装仅在 Scoop 未检测为可用时提供。
- 可配置项仅包括官方安装脚本支持的 `ScoopDir`、`ScoopGlobalDir`、`ScoopCacheDir`、`NoProxy`、`Proxy`、`ProxyCredential`、`ProxyUseDefaultCredentials`、`RunAsAdmin`;默认值与受支持的官方安装参数一致。
- 无效路径、冲突代理设置或不完整代理凭据应在执行前被发现并以可理解的方式说明。
- 涉及全局目录或管理员权限的设置应说明影响和提权路径;不把管理员权限当作另一种产品角色。
- 执行前须让用户确认将要使用的配置;执行期间本次配置不可变更。确认的配置在本机持久化供后续重装复用。

## 3. 安装任务与结果

- 确认后创建唯一的协助安装任务,并可查看任务状态、进度与日志。
- 执行成功后重新检测 Scoop;只有复检确认可用才进入日常管理功能。
- 失败时展示可理解的失败原因,保留可修改的配置并允许再次发起;再次尝试创建新任务。
- 用户取消时结果为“已取消”而非“失败”;用户仍可再次发起安装。
- 任务创建失败与任务执行失败应能区分,且均提供合适的下一步动作。
- 启动检测、校验、失败、取消和持久化提示均提供中英文版本。
