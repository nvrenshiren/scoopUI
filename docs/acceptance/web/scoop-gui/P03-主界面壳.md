# P03 · 验收标准 · 主界面壳

> 验收对象:`src/App.tsx` 与 `src/store.ts`;业务状态以 `docs/prd/flows/scoop-gui.md` 为准,当前设计约定见 `docs/design/systems/web.md`。

## 1. 入口与导航

| 用例 | 操作 | 预期结果 |
| --- | --- | --- |
| 启动门禁 | 在语言未选择、Scoop 检测中、未安装或安装中的阶段观察窗口 | 分别呈现 P02 或 P01;主界面仅在 `boot === "ready"` 后出现 |
| 工作区导航 | 依次选择已装、浏览、桶管理、Scoop 配置与设置 | 主区分别加载 P04、P05、P06、P11、P09;只有当前页面对应的导航项处于选中态 |
| 页面本地状态 | 在 P04/P05/P06 输入筛选、查询或表单草稿,切到其它页面再返回 | 离开页面时本地筛选、查询与未提交草稿重置;已提交的业务数据仍从全局状态呈现 |
| Scoop 状态 | 进入主界面并查看侧栏底部信息 | 显示已检测到的 Scoop 版本;没有版本值时显示通用 Scoop 标识 |
| 任务入口 | 点击侧栏常驻任务入口 | 打开/关闭 P08;有排队或执行任务时显示对应数量,不因主区导航变化而丢失任务状态 |

## 2. 数据加载与错误

| 用例 | 前置条件 / 操作 | 预期结果 |
| --- | --- | --- |
| 初始数据预取 | Boot Sequence 检测到 Scoop 后进入主界面 | 初始加载请求已装列表、过期状态、桶清单与 Scoop 配置;浏览结果在首次进入 P05 时读取 |
| 桶页面切换 | 首次进入 P06 或点击页面刷新 | 已添加桶与已知桶清单分别加载;两项失败状态独立,互不吞掉对方结果 |
| 主区读取失败 | 让当前页面所需的数据请求失败 | 当前数据区展示错误状态与重试入口,主界面导航仍可用;不自动返回 P01 |
| 单实例 | 应用已运行时再次启动 | 不创建第二个独立实例;原窗口恢复并获得焦点,当前视图与任务保持不变 |

## 3. 语言与主题

- 在 P09 切换中文/英文后,导航、页头、当前页面与打开的应用级浮层立即更新为所选语言。
- 切换暗色、亮色或跟随系统后,当前界面按对应 COHESION 主题呈现;主题与语言偏好持久化失败时提示用户,不回滚本次已生效的选择。
- 主界面和任务入口不得出现无配套翻译的面向用户文案。

## 4. 文档范围

本文件只验证 P03 的启动门禁、路由、常驻任务入口、跨页面状态和全局偏好。不重复 P04–P11 的页面内操作与业务状态机,视觉规则不在本文件维护。
