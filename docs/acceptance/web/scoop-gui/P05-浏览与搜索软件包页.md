## 1. 目录范围与搜索

- 目录包含当前已添加桶中可发现的软件包,不因软件已安装而从目录中消失。
- 每个目录项应能识别其名称、来源和本机安装状态;已安装项不得误示为可安装。
- 按关键字搜索能定位匹配的软件包;清除查询后恢复当前完整目录。
- 目录为空、搜索无结果、读取失败应分别说明,读取失败提供重试。
- 桶集合发生变化后,已加载目录范围应同步更新。

## 2. 软件包操作

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 查看软件详情 | 选择目录项 | 可查看该软件包详情,并返回原业务上下文 |
| 安装未安装项 | 请求安装 | 为该目标创建一条独立安装任务,用户可查看状态与日志 |
| 安装已安装项 | 尝试再次安装 | 不重复创建安装任务;当前已安装状态保持清晰 |
| 安装成功 | 等待任务完成 | 目录项仍在目录中并标记为已安装 |
| 安装失败 | 等待任务失败 | 说明失败原因;软件包保持未安装,用户可重新发起并创建新任务 |
| 安装取消 | 取消活跃任务 | 任务标记为已取消,软件包保持未安装 |

## 3. 文档范围
