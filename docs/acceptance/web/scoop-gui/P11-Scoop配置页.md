# P11 · 验收标准 · Scoop 配置管理

> 文档层级:页面级契约(QA 验收标准)
> 上游依据:`docs/prd/pages/web/scoop-gui/P11-Scoop配置页.md`、`docs/prd/flows/scoop-gui.md` §1.10、`docs/architecture/api/scoop-gui.md` §3.16~§3.18

## 1. 配置范围与读取

- 覆盖当前支持的 32 个配置项,无遗漏或重复;31 个标量项可编辑,`private_hosts` 只读。
- 每项提供可理解的名称、说明、原始键名和当前值;控件及值表达方式适配配置类型。
- 能区分未设置值与显式设置值;读取失败时说明原因,不把旧值冒充为当前值。
- 配置项所属类别信息可用于帮助用户理解;不限定类别分区、数量、顺序或页面组织形式。

## 2. 写入与恢复默认

- 编辑任一可写项后即时写入 Scoop,无需整页保存;成功后呈现新值。
- 写入失败后该项恢复为写入前的有效值,并提供可理解的反馈。
- 已设置的可写项可恢复为 Scoop 默认行为;未设置项不得误报为已设置。
- 配置读取、写入和恢复默认均不创建 InstallJob,也不影响软件包或桶状态。
- 目录类项写入或恢复默认前,说明配置改变不会搬移既有数据并要求用户确认;取消时不写入。

## 3. 敏感值与复杂值

- 令牌等敏感项默认不暴露明文;用户明确请求查看时才临时显示。
- 敏感值不得进入网络请求或应用日志。
- `private_hosts` 可读取并以只读形式说明;不提供可能破坏复杂对象结构的编辑操作。

## 4. 国际化与文档范围

配置名称、说明、状态和错误提示提供中英文。本文只验证支持范围和读写行为,不规定分类布局或控件排列;键名与 IPC 契约见 `docs/architecture/api/scoop-gui.md` 和 `src/scoopConfig.ts`。
