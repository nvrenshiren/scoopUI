# P03 · 验收标准 · 主流程与功能入口

> 上游依据:`docs/prd/pages/web/scoop-gui/P03-主流程与功能入口.md`、`docs/prd/flows/scoop-gui.md` 与适用的功能 PRD。实现代码是被验收对象,不覆盖功能要求。

## 1. 启动门禁与数据加载

| 用例 | 操作 | 预期结果 |
| --- | --- | --- |
| 启动门禁 | 分别在未选择语言、检测 Scoop、未安装 Scoop、协助安装中的状态观察应用 | 仅在语言已确定且 Scoop 可用后进入主流程;其他状态呈现对应引导或检测内容 |
| 初始读取 | 检测到 Scoop 后进入主流程 | 请求已装软件、过期状态、已添加/已知桶和受支持 Scoop 配置;软件目录首次在进入浏览能力时读取 |
| 独立失败 | 令其中一个初始数据源失败,检查其它功能 | 失败范围局限于对应数据;无关功能仍可访问与重试 |
| 单实例 | 应用已运行时再次启动 | 不创建第二个独立实例;原实例恢复并获得焦点 |

## 2. 功能入口与任务访问

| 用例 | 操作 | 预期结果 |
| --- | --- | --- |
| 软件包能力 | 从主流程打开软件目录与已装软件维护能力 | 可按 P04/P05 契约查看软件、搜索、维护并查看详情 |
| 软件源能力 | 打开桶管理能力 | 可按 P06 契约查看、添加或移除桶 |
| Scoop 配置 | 打开 Scoop 配置能力 | 可按 P11 契约查看受支持配置并编辑可写项 |
| 应用设置 | 打开设置能力并切换语言 | 当前界面的用户文案即时切换,且符合 P09 契约 |
| 长时任务访问 | 查看当前与历史任务信息 | P08 可在主流程内访问;查看方式不改变任务状态 |
| 任务自动展示 | 发起安装、卸载、更新或桶操作 | 创建任务后自动显示 P08;任务数据不因查看其它功能而丢失 |

## 3. 运行期间异常

- Scoop 在运行期间失效时,受影响的数据区段提供可理解的错误与重试入口。
- 读取失败不应自动触发首次协助安装,也不应锁死其它可用功能。
- 界面语言和主题变化不应改变软件包、桶或 InstallJob 业务状态。

## 4. 文档范围

本文件验证启动门禁、初始读取边界、主流程功能可达性与跨功能状态。不限定功能入口位置或页面排列。
