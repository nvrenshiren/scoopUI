## 1. 已装软件与状态

- 仅展示本机已通过 Scoop 安装的软件包,并提供足以识别目标的名称与版本信息。
- 按关键字筛选后只保留匹配项;清除筛选恢复完整已装清单。
- 与所属桶内版本比较后,准确标识已安装软件是否过期。过期信息未知时不得误报为最新或过期。
- 刷新已装清单或检查更新后,数据与本机 Scoop 状态一致;单项检查失败不应隐藏成功读取的已装信息。

## 2. 详情与单项维护

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 查看详情 | 选择已装软件包 | 可查看该软件包可获得的详细信息 |
| 卸载 | 请求卸载并确认目标 | 仅为该目标创建卸载任务;取消确认时不创建任务 |
| 更新过期项 | 请求更新并确认目标 | 仅对过期软件包创建更新任务;非过期软件包不可作为更新目标 |
| 操作成功 | 等待任务完成 | 目标状态更新;更新后过期标记清除,卸载后目标从已装清单移除 |
| 操作失败 | 等待任务失败 | 保留卸载前/更新前的有效状态,说明失败原因并允许从来源功能重新发起 |
| 操作取消 | 取消排队中或执行中的任务 | 目标恢复操作前状态,任务显示为已取消而非失败 |

## 3. 批量维护

- 用户可选择多个已装软件包并确认后批量卸载;未选中的对象不受影响。
- 用户可选择部分过期软件包或选择全部过期软件包进行批量更新;不得更新未选中的或未过期的软件包。
- 确认前可识别批量操作的目标;取消确认时不创建任何任务。
- 每个目标创建独立任务并独立显示成功、失败或取消结果;单项失败或取消不影响其他目标。
- 空清单、无选中目标或没有过期项时,不得创建空任务。

## 4. 数据反馈与异常

- 单个软件包操作成功后,其状态及时更新,不应让无关软件包被错误标记、移除或覆盖。
- 已装清单为空时,说明暂无已装软件并提供浏览软件目录的下一步。
- 筛选无结果与读取失败应有不同提示;读取失败时提供重试。
- 过期比对失败时明确说明状态暂不可确认;不得把缺失结果解释为“最新”。
- 提示与状态应提供中英文表达,且不只依靠颜色区分。

## 5. 文档范围

本文件验证已装软件的识别、单项与批量维护、状态更新和错误恢复;不规定表格、列、页面排布或操作控件的位置。业务规则见 `docs/prd/flows/scoop-gui.md`。
