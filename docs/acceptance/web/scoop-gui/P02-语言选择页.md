## 1. 验收范围

验证首次启动时的语言选择、持久化和启动流程衔接。验收对象是功能行为，不限定选项控件、确认方式、页面布局或文案的位置。

## 2. 选择条件

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 本机尚无语言偏好 | 启动应用 | 用户必须在中文与 English 中选择一种后才能继续；不得跳过或自动选定 |
| 本机已有语言偏好 | 启动应用 | 使用已保存的语言继续启动，不要求重复选择 |
| 选择中文 | 选择并确认中文 | 语言立即生效，后续启动阶段使用中文 |
| 选择 English | 选择并确认 English | 语言立即生效，后续启动阶段使用英文 |
| 语言保存失败 | 在持久化失败环境中选择语言 | 本次运行仍按所选语言继续；用户获知选择未能保存且后续启动可能回退 |

## 3. 跨流程行为

- 选择完成后,启动流程继续检测 Scoop;检测成功时进入日常管理功能,未检测到时进入协助安装流程。
- 选择语言不得改变软件包、桶或长时任务状态。
- 中文与英文文案均完整可用;交互应支持键盘访问,焦点与文字对比符合设计系统要求。
- 保存失败提示不得阻断本次启动或被误报为语言选择失败。
