# P09 · 验收标准 · 应用设置与语言切换

> 文档层级:页面级契约(QA 验收标准)
> 上游依据:`docs/prd/pages/web/scoop-gui/P09-设置与语言切换页.md`、`docs/prd/flows/scoop-gui.md` §1.8 / §2.5
> 视觉与可访问性依据:`docs/design/systems/web.md`

---

## 1. 语言

- 可选择中文或 English,并能识别当前选择;不得出现第三种语言或导入语言包能力。
- 切换后所有面向用户的文案立即改变,无需重启;后续启动使用持久化的选择。
- 保存失败时本次切换仍生效,同时说明后续启动可能回退;不得阻断其他操作。
- 重复选择当前语言不应改变业务状态或造成错误反馈。

## 2. 主题

- 提供亮色、暗色和跟随系统三种主题偏好。
- 新配置默认使用暗色;选定主题后立即应用并持久化。
- 跟随系统模式会随操作系统外观变化;亮色与暗色下文字、焦点和状态对比均可辨认。
- 保存失败时当前主题仍生效,并说明持久化未完成。

## 3. 只读摘要与隔离

- 可查看产品协助安装 Scoop 时保存的安装配置摘要及版本信息;未保存时说明暂无摘要。
- 代理凭据等敏感值不得以明文暴露。
- 应用偏好与 Scoop 自身运行配置分别管理;修改语言或主题不得改变软件包、桶或任务状态。
- 文案中英文完整,键盘可访问,符合 `docs/design/systems/web.md`。

## 4. 文档范围

本文件验收设置能力与其影响范围,不规定分区、选项顺序或控件布局。Scoop 自身配置由 P11 契约覆盖。
