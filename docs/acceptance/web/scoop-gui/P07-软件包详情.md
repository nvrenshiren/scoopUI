## 1. 信息展示

- 可从软件目录或已装软件维护中查看对应软件包详情,并能返回原业务上下文。
- 展示 `scoop info` 返回的可用信息;软件包间字段可不同,不得假设固定字段集合。
- 包名、版本、来源和说明等信息清晰可识别;未知字段应保留原始名称和值,不得因未翻译而丢失。
- 详情读取失败时说明原因,允许重试或返回来源功能;失败不得错误改变软件包安装状态。
- 详情信息与状态按当前有效数据展示;语言切换只翻译界面标签,不改写 Scoop 返回的原始值。

## 2. 操作权限与确认

| 软件包状态 | 可执行操作 |
| --- | --- |
| 未安装且无活跃任务 | 安装 |
| 已安装且未过期,无活跃任务 | 卸载 |
| 已安装且过期,无活跃任务 | 卸载或更新 |
| 目标已有排队中或执行中任务 | 不得重复发起冲突操作,并能判断目标正在处理 |

- 安装成功创建一个目标明确的独立任务。
- 更新和卸载在执行前要求用户确认目标;取消确认时不创建任务。
- 任务创建后可从任务信息查看状态与结果;重复操作不得覆盖已有任务记录。
- 失败后从来源功能重新发起操作时创建新任务;已取消任务不得误报为失败。
