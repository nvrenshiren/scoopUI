# P10 · 验收标准 · 空状态与读取错误

> 文档层级:跨功能契约(QA 验收标准)
> 验收依据:`docs/prd/pages/web/scoop-gui/P10-空状态与错误页.md` 与各功能 PRD;实现代码是被验收对象,不覆盖功能要求。

---

## 1. 覆盖范围

P10 是跨功能状态,不单独导航。当前验收范围包括 P04 已装软件、P05 软件目录和搜索、P06 桶数据区段。P08 的长时任务失败由 `P08-长时操作任务.md` 验收;配置读取失败按 P11 的契约处理。

## 2. 空数据与搜索无结果

| 用例 | 前置条件 / 操作 | 预期结果 |
| --- | --- | --- |
| P04-EMPTY | 已装列表成功读取,结果为空 | 显示“尚无已装软件”的说明,并告知用户可继续浏览软件目录 |
| P04-NOMATCH | 已装列表非空,过滤条件无匹配项 | 说明没有符合条件的项目;清除过滤后恢复列表 |
| P05-EMPTY | 已添加桶软件目录成功读取,没有目录项 | 说明当前没有可浏览的软件目录,提供检查或添加软件源的下一步 |
| P05-NOMATCH | 输入关键字后没有匹配项 | 说明无匹配结果;搜索输入仍可修改或清除 |
| P06-EMPTY | 已添加桶清单或已知桶清单成功读取,对应结果为空 | 显示与该清单相符的空状态;仍可检查另一清单或添加自定义桶 |

## 3. 读取错误与恢复

| 用例 | 前置条件 / 操作 | 预期结果 |
| --- | --- | --- |
| P04-ERROR | 已装列表请求失败 | 显示读取失败提示和重试入口;其它功能仍可访问 |
| P05-ERROR | 软件目录请求失败 | 显示目录读取失败提示和重试入口;搜索输入仍可用 |
| P06-ERROR | `bucket_list` 或 `bucket_known` 单独失败 | 标明失败的是哪组数据并提供重试;成功返回的另一组数据继续可用 |
| RUNTIME-SCOOP | 主流程运行期间 Scoop 命令失效 | 受影响的数据区段提示无法读取;产品不自动返回 P01 或重新发起协助安装 |
| RETRY | 在任一读取错误区段触发重试 | 重新请求对应数据;成功时清除该错误并恢复数据呈现 |

## 4. 一致性检查

- 空状态、搜索无结果和读取失败不能互相混淆。
- 提示与操作符合当前语言;错误消息用用户可理解的说明,不依赖底层堆栈信息。
- 用户取消任务不应由 P10 描述成读取失败或长时任务失败。
- 读取错误不应导致应用崩溃、锁死主流程或清除已成功读取的无关数据。

## 5. 文档范围

本文件仅验收空数据、无匹配结果和读取错误。页面视觉规则见 `docs/design/systems/web.md`;长时任务和配置编辑错误分别由 P08 与 P11 验收文档覆盖。
