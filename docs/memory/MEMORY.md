# 项目记忆

## Scoop 代理与 Git

- Scoop 的 `proxy` 配置用于 Scoop 自身的 HTTP 下载，也会传给 Scoop 内部执行的 Git 网络操作；它不会自动成为全局代理，也不会自动作用于单独启动的 Git 命令。
- 执行独立的 `fetch`、`pull`、`push`、`clone` 等联网 Git 操作时，若需要沿用 Scoop 代理，应读取其有效配置并仅传给该命令进程（例如使用进程级 HTTP(S) 代理环境变量或 Git 命令级配置），不要修改全局配置。`default`、`none` 和系统代理应按 Scoop 的实际含义处理。
- 不猜测或硬编码代理地址，不把代理凭据写入仓库、提交记录或日志输出。纯本地 Git 操作无需代理。

## UI 需求与设计系统

- UI 重组以当前功能需求为依据，不把既有页面树、导航位置或区域排列当成设计约束。当前范围包括软件包目录浏览与已装维护、桶管理、Scoop 配置、语言与主题设置，以及统一的长时任务反馈。
- scoopUI 的主题与组件沿用 `D:\Work\dawi\design` 的逐科 shadcn 语义 Token 和现有 Radix/shadcn 源码；颜色、浅深模式和交互状态以正式主题文件为准，不在页面另设品牌色。
- 桌面窗口使用项目 UI 实现最小化、最大化/还原和关闭控件；普通界面内容不可鼠标选中或通过 Ctrl+A / Cmd+A 全选，输入框与可编辑文本保留正常选择能力。
