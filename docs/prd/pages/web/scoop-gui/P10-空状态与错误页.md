# P10 · 空状态与读取错误

> 文档层级:页面级契约
> 适用范围:Windows 桌面端 scoop-gui 模块
> 上游依赖:project.md / glossary.md / flows/scoop-gui.md / modules/scoop-gui.md
> 下游引用:developer(据此实现状态反馈)/ qa(据此验收)

---

## 1. 目的

当软件包或软件源数据为空、搜索无匹配结果或读取失败时,说明当前状态及可执行的下一步。P10 是跨功能的状态呈现契约,不是可独立访问的页面。

## 2. 功能范围

- F19:对空数据、搜索无结果和读取失败提供符合当前语言的业务提示及适用的重试方式。
- 用户取消不应被描述为失败。
- 长时任务失败与取消由 P08 展示状态和日志;P10 不替代任务反馈。

## 3. 状态与后续操作

| 状态 | 处理要求 |
| --- | --- |
| 已装列表为空 | 说明当前没有已安装软件;允许用户继续浏览软件目录 |
| 软件目录为空 | 说明当前没有可浏览的目录项;允许用户检查或添加软件源 |
| 搜索无匹配项 | 说明当前关键字没有匹配结果;保留修改或清除查询的路径 |
| 桶列表为空 | 说明当前状态;允许用户查看已知桶或添加自定义桶 |
| 数据读取失败 | 说明受影响的数据无法读取,并提供重试入口;其它可用功能保持可达 |
| 运行期间 Scoop 不可用 | 提示检查 Scoop 命令并重试;不自动进入首次安装流程 |

实体状态和异常处理规则以 `flows/scoop-gui.md` §1.9 与 §2 为唯一来源。页面验收按具体数据源和页面文档分别覆盖。

## 4. 验收要点

- ✅ 空列表与搜索无匹配结果应提供不同的解释。
- ✅ 用户可在无匹配结果时调整或清除查询。
- ✅ 桶或软件包读取失败时显示重试方式,且不将错误伪装成空数据。
- ✅ 数据源之间的失败相互隔离,一个区段失败不应阻断无关功能。
- ✅ Scoop 运行期间失效时不自动进入首次协助安装。
- ✅ 错误文案按当前界面语言呈现,用户取消不归类为失败。
- ✅ P10 不作为独立导航入口,也不承担 P08 的任务状态和日志展示。

## 5. 文档范围声明

本文件规定空数据、无结果与读取错误的反馈要求,不描述具体布局、颜色、组件或页面结构。
