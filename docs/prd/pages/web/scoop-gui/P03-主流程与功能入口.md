# P03 · 主流程与功能入口

## 1. 目的

在首次启动条件满足后承载产品的日常功能,让本机用户可以浏览与维护软件包、管理软件源、查看或修改受支持的 Scoop 配置、调整应用设置并访问长时任务。页面的具体组织方式由功能需求决定;本契约不指定导航位置或固定布局。

## 2. 功能清单

- F01 / F02:浏览已添加桶中的软件目录,区分本机已安装状态并搜索软件。
- F03 / F04:查看已安装软件的过期状态和单包详情。
- F05~F08:安装、卸载、更新单包或批量维护所选软件包。
- F09~F12:查看、添加和移除软件源。
- F14:在产品内切换界面语言。
- F17 / F19:查看长时任务进度与结果,处理错误提示。
- F18:重复启动时唤起并聚焦已运行实例。
- F20:查看并管理产品支持的 Scoop 配置项。

## 3. 页面流转

### 3.1 入口

Boot Sequence 满足 `flows/scoop-gui.md` §2.6.3-8 的条件后进入 P03。若 Scoop 不可用或协助安装尚未完成,留在 P01。

### 3.2 内部能力

用户可从主流程访问软件包浏览与维护(P04/P05)、桶管理(P06)、Scoop 配置(P11)和应用设置(P09)。长时任务信息(P08)可从主流程访问,发起长时操作后应能及时看到进度。切换业务能力时,各来源功能的临时搜索、筛选或草稿按对应契约处理。

### 3.3 出口

- P04/P05 的软件包操作按 `flows/scoop-gui.md` §1.3~1.6 流转。
- P06 的桶操作按 `flows/scoop-gui.md` §1.7 流转。
- P09 的语言切换按 `flows/scoop-gui.md` §1.8 流转。
- P11 的 Scoop 配置修改按 `flows/scoop-gui.md` §1.10 流转。
- 用户离开任务信息后,任务继续运行;重新访问时仍可查看保留的状态与结果。

## 4. 交互说明

- **进入主流程**:语言已确定且 Scoop 可用后,呈现主界面;开始读取已装软件、过期状态、桶清单与产品支持的 Scoop 配置。软件目录在用户开始浏览时加载。
- **切换业务能力**:用户选择软件包、软件源、Scoop 配置或设置能力后,可继续执行其对应操作;某一数据源读取失败不应阻断无关能力。
- **查看长时任务**:用户可访问任务信息查看状态与日志;新的长时操作启动后应能及时查看其进度。
- **运行期间 Scoop 不可用**:只提示受影响的数据不可读取并提供适用的重试方式,不自动重启首次协助安装流程。
- **再次启动**:已有实例被唤起并聚焦,不创建第二个独立实例。

## 5. 验收要点

- ✅ 只有 Boot Sequence 进入“进入主界面”后,用户才可使用 P03。
- ✅ 主界面能够到达本项目当前功能范围内的软件包、软件源、Scoop 配置与应用设置能力。
- ✅ 用户可访问长时任务信息;发起长时操作后能及时查看任务进度。
- ✅ 某数据源读取失败不应让无关业务能力不可用。
- ✅ 运行期间 Scoop 失效时不应自动跳转到首次协助安装流程。
- ✅ 再次启动产品时唤起并聚焦已有实例。
- ✅ 主界面不存在登录、多用户或角色切换能力。

## 6. 文档范围声明

本文件规定主流程入口、可用功能和跨功能行为,不规定页面布局、导航位置、颜色或组件视觉细节。
